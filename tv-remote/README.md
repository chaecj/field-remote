# 현장 리모컨 — 설치·사용 안내

휴대폰(갤럭시 Z플립7) 하나로 촬영장 소품 TV를 제어합니다.
TV 뒤 USB에 꽂은 작은 동글이 휴대폰의 블루투스 명령을 받아 **USB 키보드·마우스·미디어키**와 **적외선(IR) 리모컨 신호**로 TV에 전달합니다. 전자칠판·태블릿처럼 블루투스 키보드를 받는 기기는 **선 없이 블루투스 키보드**로도 연결됩니다. Wi-Fi와 인터넷이 없어도 됩니다.

```
휴대폰 앱 ──블루투스──▶ 동글(AtomS3 Lite) ──USB──▶ TV (키보드·마우스로 인식)
                                      ├──IR───▶ TV 리모컨 수신부
                                      └──블루투스 키보드──▶ 전자칠판·태블릿
```

---

## 1. 준비물

| 품목 | 수량 | 검색어 |
|---|---|---|
| M5Stack AtomS3 Lite | TV 대수만큼 | `AtomS3 Lite` (디바이스마트, 엘레파츠 등) |
| USB-A(수) ↔ USB-C(수) 짧은 데이터 케이블 (10~30cm) | 동글 수만큼 | `USB A to C 데이터 케이블 짧은` — 동글의 USB-C는 구멍(암)이라 C 쪽도 수여야 함. 충전 전용 케이블은 안 됨. 케이블 대신 `USB A to C 젠더 수수`(직결 어댑터)도 가능 |
| USB 연장선 30cm~1m (권장) | 동글 수만큼 | `USB 2.0 연장 케이블` |
| 소형 USB 허브 (선택) | 1~2개 | USB 포트가 하나뿐인 TV에서 소품 USB와 같이 꽂을 때 |

USB 연장선을 쓰면 동글을 TV 앞쪽 아래(리모컨 수신부 근처)에 테이프로 붙여 둘 수 있어서 IR 신호까지 확실하게 들어갑니다.

## 2. 동글에 펌웨어 넣기 (PC에서 한 번만)

### 방법 A: 웹 브라우저로 굽기 (프로그램 설치 없음, 추천)
1. PC에서 **크롬**으로 <https://espressif.github.io/esptool-js/> 를 엽니다.
2. AtomS3 Lite의 **리셋 버튼(옆면)을 2초간 눌러** 안쪽 초록 LED가 켜지면 손을 뗍니다. (다운로드 모드)
3. USB-C 케이블로 PC에 연결하고 **Connect** → 목록에서 포트 선택.
4. Flash Address `0x0`, 파일은 `firmware/TVRemoteDongle.merged.bin` 을 선택하고 **Program**.
5. 끝나면 케이블을 뺐다 다시 꽂습니다. LED가 **파란색**이면 성공.

### 방법 B: Arduino IDE
1. 보드 매니저에서 **esp32 by Espressif (3.3 이상)** 설치.
2. `firmware/TVRemoteDongle/TVRemoteDongle.ino` 열기.
3. 도구 메뉴 설정
   - 보드: **M5AtomS3**
   - USB Mode: **USB-OTG (TinyUSB)** ← 이게 아니면 컴파일 오류로 알려 줍니다
   - USB CDC On Boot: **Disabled**
4. 리셋 버튼 2초 → 초록 LED 확인 → 업로드.

> 펌웨어를 다시 넣을 때도 항상 **리셋 2초 → 초록 LED** 상태에서 해야 합니다. 평소에는 USB 키보드로 동작하기 때문입니다.

## 3. 휴대폰 앱 설치 (안드로이드 앱)

앱 파일(APK)은 GitHub가 클라우드에서 자동으로 만들어 줍니다. PC에 개발 프로그램을 깔 필요가 없습니다.

### 처음 한 번: GitHub에 올리기 (PC에서)
1. <https://github.com> 가입 → 오른쪽 위 **+ → New repository**
   - 이름: `field-remote`, **Private**(나만 보기) 선택 → **Create repository**
2. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
3. 압축을 푼 `tv-remote` 폴더 **안의 내용 전부**(`.github`, `android`, `app`, `firmware`, `README.md`)를 창에 끌어다 놓고, 아래 **Commit changes**를 누릅니다.
4. 위쪽 **Actions** 탭을 누르면 ‘안드로이드 앱 빌드’가 돌아갑니다. 5분 정도 뒤 초록 체크가 뜨면 완료.
   - 처음에 Actions 사용 확인 버튼이 보이면 눌러 주세요.
   - Actions 탭에 아무것도 없으면 `.github` 폴더가 빠진 것입니다. **Actions → set up a workflow yourself**를 누르고, `.github/workflows/android.yml` 파일 내용을 그대로 붙여 넣은 뒤 **Commit**하세요.

### 휴대폰에 설치
1. Z플립7 크롬으로 GitHub에 로그인하고, 저장소의 **Releases**(오른쪽 또는 아래쪽)를 엽니다.
2. 맨 위 ‘현장 리모컨 N’의 **field-remote.apk**를 눌러 내려받습니다.
3. 다운로드한 파일을 누르면 설치 화면이 나옵니다.
   - ‘이 출처의 앱 설치 허용’을 묻으면 **허용**합니다.
   - Play 프로텍트가 ‘알 수 없는 앱’이라고 경고하면 **세부정보 → 그래도 설치**를 누릅니다. 내가 만든 앱이라 스토어 등록이 안 되어 있을 뿐입니다.
4. 앱을 열면 블루투스·주변 기기·알림 권한을 묻습니다. 모두 **허용**하세요.

### 업데이트
새 파일을 받으면 같은 저장소에 다시 끌어다 놓고(같은 이름은 덮어쓰기) **Commit**하세요. 새 APK가 Releases에 올라오고, 설치하면 저장한 TV·매크로는 그대로 남습니다.

### 안드로이드 앱에서만 되는 것
- **볼륨 버튼 클리커**: 클리커 탭에서 켜면 폰 옆 볼륨 버튼으로 슬라이드를 넘깁니다(아래 = 다음, 위 = 이전). **화면이 꺼져 있어도** 됩니다.
- **동글 없이 전자칠판 연결**: TV 설정 탭 → **이 휴대폰을 블루투스 키보드로 쓰기**. 휴대폰이 직접 블루투스 키보드·마우스가 됩니다. (IR은 동글이 있어야 합니다)
- **연결 유지**: 앱을 내리거나 화면을 꺼도 동글 연결이 끊기지 않습니다. 알림창에 ‘현장 리모컨’이 떠 있는 동안 유지됩니다.

> 웹앱으로 쓰고 싶다면 `app` 폴더를 GitHub Pages에 올려 크롬으로 열어도 됩니다. 다만 위 세 가지 기능은 빠집니다.

## 4. 현장에서 쓰는 순서

1. TV 뒤 USB 포트에 동글을 꽂습니다. (연장선으로 앞쪽에 빼 두면 IR까지 확실)
2. **TV 본체 전원 버튼**으로 TV를 켭니다. 동글 LED가 파랗게 켜집니다.
3. 앱에서 **+ 동글 추가** → 목록의 `TVR-xxxx` 선택. LED가 초록 → 청록으로 바뀌면 TV까지 인식된 상태입니다.
4. **TV 설정** 탭에서 이름을 붙입니다 (예: 거실 TV). 어떤 동글이 어떤 TV인지 헷갈리면 **동글 LED 깜빡이기**를 누르거나, 동글 윗면 버튼을 누르면 앱에서 해당 TV가 반짝입니다.
5. (선택) **브랜드 찾기**: 전원 신호를 브랜드별로 하나씩 보내서 TV가 꺼지는 브랜드를 저장합니다. 이후 외부입력·설정 메뉴가 IR로 정확하게 동작합니다.

### 동글 LED
| 색 | 뜻 |
|---|---|
| 파랑 | 휴대폰 연결 대기 |
| 초록 | 휴대폰 연결됨, TV가 아직 USB 장치로 인식 안 함 |
| 청록 | 휴대폰 연결 + 기기 인식 완료 (USB 또는 블루투스 키보드, 정상) |
| 흰색 깜빡 | 명령 전송 |
| 주황 깜빡 | 이 동글 찾기 / 버튼 눌림 |

---

### 전자칠판에 블루투스로 연결하기 (선 없이)
1. 동글을 **보조배터리나 충전기**에 꽂아 켭니다. (전자칠판 USB에 꽂아도 됩니다)
2. 휴대폰 앱에서 그 동글을 먼저 추가해 둡니다.
3. 전자칠판의 **설정 → 블루투스 → 새 기기 검색**에서 `TVR-xxxx`(키보드 아이콘)를 눌러 연결합니다. 비밀번호는 묻지 않습니다.
4. 앱의 TV 설정 탭에서 ‘블루투스 키보드: 1대 연결됨’이 보이면 완료. 동글 LED는 청록이 됩니다.
5. 클리커 탭 → **노트북·전자칠판** → 프로그램에서 **전자칠판 (안드로이드)** 선택. 윈도우 기반 전자칠판이면 **파워포인트 (Windows)**를 고르세요.

- **휴대폰의 블루투스 설정에서는 동글을 연결하지 마세요.** 휴대폰이 동글을 키보드로 가져가 버립니다. 휴대폰은 항상 앱 안에서만 연결합니다.
- 동글 하나에 휴대폰 1대 + 블루투스 키보드 기기 2대까지 동시에 연결됩니다.
- 전자칠판을 바꿀 때 연결이 안 되면 TV 설정 탭의 **블루투스 연결 기록 지우기**를 누르세요.

## 5. 앱 화면

- **리모컨**: 전원, 외부입력, 홈, 설정, 방향키·확인, 뒤로, 나가기, 정보, 음량, 채널, 음소거, 재생 버튼, 숫자 키패드. 방향키·음량·채널은 누르고 있으면 연속으로 들어갑니다.
- **터치패드**: TV 화면에 마우스 커서를 띄워 메뉴를 직접 누릅니다. 한 손가락 이동, 톡 치면 클릭, 두 손가락 스크롤. Wi-Fi 비밀번호 같은 영문 입력도 여기서 합니다.
- **클리커**: 발표용 리모컨. 두 가지로 씁니다.
  - **노트북·전자칠판**: 동글을 노트북·전자칠판 USB에 꽂거나, 전자칠판에 블루투스 키보드로 연결합니다. 큰 ◀ ▶ 버튼으로 슬라이드를 넘기고, 처음부터 시작·현재 장부터·끝내기·검은 화면·흰 화면·레이저·번호로 이동을 지원합니다. 파워포인트(Windows/Mac), 키노트, 구글 슬라이드, 전자칠판(안드로이드), 사진 보기·PDF 중에서 고르면 단축키가 맞춰집니다.
  - **TV 사진 넘기기**: TV에 꽂은 소품 USB의 사진을 넘깁니다. 그 TV의 리모컨 설정을 그대로 씁니다.
  - 발표 창이 노트북 화면 맨 앞에 떠 있어야 키가 들어갑니다. Mac에 처음 꽂을 때 ‘키보드 설정 지원’ 창이 뜨면 그냥 닫으세요.
- **화면 조정**: 설정 메뉴 이동, 밝기·명암 값을 ×5, ×10씩 한 번에 조절, **바로가기 매크로**(예: ‘설정 → 화면 → 밝기’를 한 번 녹화해 두면 버튼 하나로 이동).
- **TV 설정**: 이름, 브랜드, 보내는 방식(자동/USB 우선/IR 우선), **버튼 다시 지정**.
- **동시 제어**(위쪽 버튼): 여러 TV를 골라 같은 명령을 한 번에 보냅니다. 예: 전체 HDMI1, 전체 음소거.

### 버튼이 반응하지 않을 때
TV마다 USB 키를 받아들이는 방식이 조금씩 다릅니다. **TV 설정 → 버튼 다시 지정 → 편집 시작** 후 리모컨 탭에서 그 버튼을 누르면, IR 코드·USB 키 후보를 하나씩 **보내 보기**로 시험하고 맞는 것을 **이걸로** 저장할 수 있습니다. TV별로 따로 저장됩니다.

목록에 없는 브랜드는 인터넷에서 `모델명 pronto code` 로 찾은 코드를 붙여 넣어 쓸 수 있습니다.

## 6. 할 수 있는 것과 한계

- **스마트TV**(삼성, LG, 구글TV, 안드로이드TV 등): USB 키보드·마우스를 인식하므로 설정 메뉴(밝기, 명암, 화면 모드 등)까지 전부 휴대폰으로 조작할 수 있습니다. 메뉴 키가 안 먹는 TV라도 터치패드 커서로 화면의 설정 아이콘을 누르면 됩니다.
- **스마트 기능이 없는 구형 TV**: USB 포트가 사진·영상 재생 전용이라 키보드·마우스를 인식하지 않습니다. 이 경우는 IR(브랜드 코드)로 제어합니다.
- **전원 켜기**: 대부분의 TV는 꺼지면 USB 전원도 끊겨서 동글도 꺼집니다. 그래서 켤 때는 TV 본체 버튼을 씁니다.
  - TV를 꺼도 동글 LED가 켜져 있다면 그 TV는 대기 중에도 USB 전원을 주는 모델입니다. 이때는 브랜드를 저장해 두면 앱의 **전원** 버튼(IR)으로 켜기도 됩니다.
  - 휴대폰으로 꼭 켜야 하는 TV가 있으면, 동글 하나를 **보조배터리**에 꽂아 TV 앞에 두세요. 같은 펌웨어 그대로 IR 리모컨 역할만 합니다. (앱에서 보내는 방식을 ‘IR 우선’으로)
- **IR 코드**: 삼성·LG는 널리 쓰이는 표준 코드라 대부분 맞습니다. 소니·파나소닉·필립스·도시바는 모델에 따라 일부 버튼이 다를 수 있어 ‘버튼 다시 지정’으로 맞추면 됩니다.

## 7. 카메라 플리커·밝기 맞추기

- **백라이트(밝기)는 최대 근처**로 두고, 화면을 어둡게 할 때는 명암·감마로 낮추세요. 많은 TV가 백라이트를 낮출 때 빠르게 깜빡이는 방식(PWM)으로 밝기를 줄여서 카메라에 줄무늬가 생깁니다.
- 그래도 너무 밝으면 화면에 **ND 필름**을 붙이거나 소품 이미지 자체를 어둡게 만드는 편이 깜빡임 없이 안전합니다.
- **절전·에코 모드, 자동 밝기(조도 센서), 동작 보정(모션 플러스·트루모션)** 을 끄세요. 테이크마다 밝기가 바뀌는 걸 막습니다.
- 화면 모드는 **영화·필름메이커 모드**가 색과 밝기가 가장 안정적입니다.
- 60Hz 화면을 24fps로 찍을 때 롤링 줄이 보이면 셔터를 **1/60(144°)** 쪽으로 맞춰 보세요.

이 메뉴들까지 가는 경로를 TV마다 매크로로 녹화해 두면 다음 촬영 때 바로 쓸 수 있습니다.

## 8. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 동글 추가 목록에 안 나옴 | 동글 LED가 파란색인지, 다른 휴대폰에 이미 연결돼 있지 않은지, 휴대폰 블루투스·위치가 켜져 있는지 |
| 앱에 ‘블루투스를 쓸 수 없어요’ | 크롬에서 https 주소(GitHub Pages)로 열었는지 |
| LED가 초록에서 청록으로 안 바뀜 | TV가 켜져 있는지, 다른 USB 포트에 꽂아 보기, 스마트TV인지 |
| 방향키는 되는데 설정·뒤로가 안 됨 | 브랜드 찾기 실행, 또는 버튼 다시 지정에서 다른 키 시험 |
| IR 버튼이 안 먹음 | 동글을 연장선으로 TV 앞쪽 수신부 근처로 빼기 |
| 동글 초기화 (이름 + 블루투스 연결 기록) | 동글 윗면 버튼을 누른 채로 USB를 꽂기 (빨간색 3번 깜빡) |
| 전자칠판 블루투스 목록에 안 보임 | 동글이 이미 3대와 연결돼 있는지 확인, TV 설정 탭에서 블루투스 연결 기록 지우기 |
